# Métis 0.1.0

Versão de desenvolvimento. A distribuição pública aguarda a licença gratuita do tldraw.

O Métis tem identidade visual própria, arquivos locais, editor de Markdown, quadro branco e integrações opcionais com IA. As configurações do aplicativo ficam separadas de outras instalações. O conteúdo inicial é criado sem conexão com a internet.

Consulte a [licença](../LICENSE) e a [página de créditos](../site/landing/public/creditos.html).
