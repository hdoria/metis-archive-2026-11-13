# Security

Report a vulnerability through [GitHub private vulnerability reporting](https://github.com/hdoria/metis/security/advisories/new) when it is enabled. If private reporting is unavailable, open an issue asking for a private contact channel without publishing exploit details or private data.

Never include API keys, access tokens, private notes or connection strings in a public report. Include the affected version, platform and enough information to reproduce the problem safely.

Updates, signing and hosted services must use this project's own configuration. The default build does not use another application's update channel or credentials.
