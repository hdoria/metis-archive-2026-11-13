# Métis landing and credits

## Scope

Concentrate project provenance in site/landing/public/creditos.html. Remove the old standalone attribution documents and repair their links. Preserve LICENSE, dependency notices and Git history. Build a Portuguese landing with the existing pine/ivory identity and an interactive note demonstration. Keep source in site/landing, with a private hosted preview.

## Acceptance

- No former product name in application code, descriptions, READMEs or marketing. The credits page is the single provenance location.
- Real links, working demo selection/search, keyboard access, responsive layout, truthful distribution status.
- Credits and the root license accompany native packaging. Public app distribution remains pending the whiteboard license.
- Build, relevant tests, independent review, verified preview, commit and push.

## Design

Pine #17463F, ivory #F6F5ED, white paper #FFFFFF, dark text #18332E and border #CCD9D2. Inter Tight for headlines and Inter for interface text; a readable note page anchors the interactive demonstration. Center the hero and leave the notebook content left aligned. The existing nested-profile symbol explains the name in the story section. Avoid fabricated testimonials, metrics and download availability.

## Stop condition

Landing and credits are checked, committed and pushed, with the preview URL and any verification limits reported. No public app release is part of this task.
