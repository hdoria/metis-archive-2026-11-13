# Métis: licensing

The source in this repository, including the desktop app, web client, mobile app and self-hosted server, remains AGPL-3.0-or-later. Métis is a free independent project. There is no proprietary cloud service or billing plan in this fork.

Keep the root LICENSE and the credits page at site/landing/public/creditos.html when redistributing. Dependencies retain their own licenses. Hosting a modified AGPL application also requires offering the corresponding source to its users under the license terms.
