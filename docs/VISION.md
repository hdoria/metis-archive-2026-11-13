# Métis

Métis é um aplicativo gratuito para guardar conhecimento em arquivos locais. Notas em Markdown e histórico em Git permitem consultar, editar e mover o conteúdo sem depender de uma conta.

O nome vem da titânide da sabedoria e do bom conselho. A identidade usa uma cabeça dentro de outra para representar um segundo cérebro. Veja [a identidade](brand/metis.md), [a licença](../LICENSE) e [as atribuições](../site/landing/public/creditos.html).
