# Centralize project attribution

## Why

Hugo wants the product, application code, descriptions and README to carry the independent identity. Project provenance belongs on one credits page, rather than separate prominent attribution documents.

## How to apply

Keep provenance and preserved notices together in the website credits page. Link to that page where needed, remove duplicated project attribution files, and keep the software license and dependency licenses intact. Audit the product source and marketing separately from the credits page. Do not reintroduce the previous brand in examples or promotional copy.
