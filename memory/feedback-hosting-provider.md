# Respect the selected hosting provider

## Why

Hugo chose Vercel for the Métis landing and metisapp.com.br as its official domain.

## How to apply

Use the root vercel.json and the established Vercel project for landing deployments. Keep the previous Sites publication only as a historical preview unless asked to retire it. Do not silently publish future changes to another host. Confirm the target team when account ownership is ambiguous, and report domain-specific DNS records from the provider rather than guessed defaults.
